## The line

> WARNING: Contents: one human. Side effects include confident wrong answers, unfinished projects, and replying 'lol' to bad news.

## How it works

`main.ts` (Node 22, standard library only) writes the line to
`/output/entry.txt` — one line, UTF-8, no trailing newline, 128 characters
(within the 160-character limit).

## Run it

```sh
node main.ts
```
